Database schema · flow-compile

A flow-compile run directory as a schema

Five of the run's artefacts, drawn as tables. state.json is the ledger of which stage ran and what it read, not a table, so it is not drawn; the import sheet is one row per annotation row and sits under it for that reason. The join into the annotation carries no error path: 05_metadata checks every field but cannot know whether a confirmed barcode is the right one.
